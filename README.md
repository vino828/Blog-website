# Blog Website

## Description
A simple and attractive blog website where users can read and explore articles about technology, lifestyle, travel, and other interesting topics.

## Features
- Clean and responsive design
- Attractive homepage
- Blog posts and articles
- Easy navigation
- User-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
